# KeyMapper 按键映射工具

Windows 本地按键映射小工具：在界面里添加「A → B」之类的规则，实时生效。纯 Python 标准库（ctypes + tkinter），零依赖。

## 功能
- **按键映射**：键盘键 / 组合键（Ctrl/Shift/Alt/Win + 键）→ 另一个键、组合键、鼠标按键、滚轮，或直接禁用
- **方式**：普通 / 按一下开始按住、再按松开 / 按住时连发 / 按一下开始连发、再按停止
- **位置点击**：按键 → 在屏幕固定位置单击或双击，可选点完鼠标回原位；全屏遮罩拾取坐标（DPI 感知）
- 鼠标中键、侧键、滚轮也能作为触发键（如 滚轮向下 → 鼠标左键）
- 同一个键可以绑多个动作，可选保留原按键功能
- 全局暂停热键：屏幕顶部浮窗 + 提示音反馈

## 使用
```bat
启动.bat          :: 用 pythonw 启动（需要 Python 3）
打包.bat          :: 用 PyInstaller 打包成 dist\KeyMapper.exe
restart.bat build :: 关掉旧进程、重新打包并启动
```
配置保存在程序同目录的 `keymap_config.json`。

## 实现
- `WH_KEYBOARD_LL` / `WH_MOUSE_LL` 低级钩子拦截源键，`SendInput` 发出目标键；用 `dwExtraInfo` 标记自己发出的事件，防止循环
- 所有输出放进队列由单独线程执行，钩子回调立即返回（在鼠标钩子里直接 SendInput 鼠标事件会死锁）

## 已知限制
- 以普通权限运行时，对管理员权限的窗口无效（需要右键以管理员身份运行）
- 个别使用 Raw Input 的游戏可能不认模拟的鼠标移动
